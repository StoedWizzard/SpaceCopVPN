SpaceCopVPN для Windows
=======================

Файлы:
  SpaceCopVPN.exe — графический клиент (запускать двойным щелчком)
  spacecop.exe    — консольные команды (ping, peers, proxy, relay, keygen…)

Установка не нужна: положите файлы в любую папку и запустите SpaceCopVPN.exe.
При первом запуске Windows SmartScreen может предупредить о неизвестном
издателе (файл не подписан): «Подробнее» → «Выполнить в любом случае».

Как пользоваться:
  1. Страница «Узлы» (◎): вставьте строку spacecop://… → «Добавить» → «Сохранить».
     Кнопка «Найти узлы» подтянет остальные узлы сети.
  2. Страница «Подключение» (⏻): режим SOCKS5 → «Подключиться».
  3. Укажите прокси в системе: Параметры → Сеть и Интернет → Прокси-сервер →
     «Настройка прокси вручную»: адрес 127.0.0.1, порт 1080 (или в браузере /
     Telegram: SOCKS5 127.0.0.1:1080).

Режим «Вся система» на Windows пока недоступен (нужен драйвер Wintun);
на Linux и Android он есть.

Сборка из исходников: GitHub Actions, workflow «Windows app»
(.github/workflows/windows.yml) — PyInstaller, Python 3.12.
