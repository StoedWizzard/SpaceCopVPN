SpaceCopVPN для Windows
=======================

Файлы:
  SpaceCopVPN.exe    — графический клиент (запускать двойным щелчком)
  spacecop.exe       — консольные команды (ping, peers, proxy, vpn, relay…)
  wintun.dll         — драйвер виртуального адаптера Wintun (для режима «Вся система»)
  WINTUN-LICENSE.txt — лицензия Wintun

Установка не нужна: держите файлы в одной папке и запускайте SpaceCopVPN.exe
(wintun.dll также встроен в exe). При первом запуске SmartScreen может
предупредить о неизвестном издателе (файл не подписан): «Подробнее» →
«Выполнить в любом случае».

Как пользоваться:
  1. Страница «Узлы» (◎): вставьте строку spacecop://… → «Добавить» → «Сохранить».
     Кнопка «Найти узлы» подтянет остальные узлы сети.
  2. Страница «Подключение» (⏻): выберите режим.
     • «Вся система (TUN)» — весь трафик компьютера через VPN. Приложение
       перезапустится с правами администратора (запрос UAC), создаст адаптер
       «SpaceCopVPN», направит в него маршрут по умолчанию и DNS. Ничего
       настраивать в системе не нужно; при отключении всё восстанавливается.
     • «SOCKS5-прокси» — без прав администратора; укажите прокси в системе:
       Параметры → Сеть и Интернет → Прокси-сервер → «Настройка вручную»:
       127.0.0.1, порт 1080 (или в браузере/Telegram: SOCKS5 127.0.0.1:1080).

Из консоли (от администратора):  spacecop.exe vpn --uri spacecop://…

Ограничения режима «Вся система»: IPv4, TCP и DNS; прочий UDP (звонки,
игры, QUIC) не переносится — браузеры сами откатываются с QUIC на TCP.

Сборка из исходников: GitHub Actions, workflow «Windows app»
(.github/workflows/windows.yml) — PyInstaller, Python 3.12, Wintun 0.14.1.
